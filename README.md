# Industrial Crafting

Industrial Crafting is a Minecraft plugin that introduces advanced crafting mechanics, ores, metals, tools, and components to enhance the gameplay experience. This plugin adds raw titanium, steel ingots, brass ingots, cast iron, and machined steel plates as new materials. It also includes tools like the adjustable wrench, precision caliper, steel gear, bearings, cutting tools, and hydraulic cylinders. The adjustable wrench allows players to fine-tune machine parameters such as speed, torque, output size, and energy consumption by shift-right-clicking on machines.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Craft the new materials and tools using the provided recipes.
2. Use the adjustable wrench to fine-tune machine parameters by shift-right-clicking on the machines.
3. Utilize the new tools and components to enhance your gameplay experience.
